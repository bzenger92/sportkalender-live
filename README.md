# Sportkalender Live

Ein kombinierter Outlook-Kalender für Real Madrid, Dallas Cowboys und Ski Alpin Männer. Automatischer ESPN-Spielplanabruf täglich per GitHub Actions. Skirennen sind vordefiniert, aber noch keine automatische FIS-Verschiebungsprüfung.

Nach Aktivierung von GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)) lautet der Abo-Link:

https://bzenger92.github.io/sportkalender-live/sportkalender.ics

In Outlook Kalender hinzufügen → Aus dem Web abonnieren. GitHub Actions: Actions → Kalender täglich aktualisieren → Run workflow einmal ausführen.
